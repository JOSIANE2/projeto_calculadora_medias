# Calculadora de médias

Aplicação em HTML, CSS e JavaScript para registrar atividades, calcular média aritmética simples e indicar aprovação. Aceita notas de 0 a 10. A nota mínima é solicitada ao adicionar a primeira atividade; cancelar preserva o formulário.

## Executar
Abra index.html no navegador. Preserve main.css, main.js e a pasta images. A fonte externa pode exigir internet.

## Limitações
Não há persistência nem pesos diferentes por atividade. Recarregue para iniciar outro cálculo e definir uma nova nota mínima.
